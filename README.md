# CarpetALAddition

**CarpetALAddition** is an extension for the Minecraft 26.1.2 Fabric mod **Carpet Mod**, adding three rules under the rule category `AFAdditon`.

## Features
### `endGatewayLoadChunk`
### `dataCommandEnhance`
